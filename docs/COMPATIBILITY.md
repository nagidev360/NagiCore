# Compatibility

## Supported
- Windows 7 SP1 with .NET Framework 4.8 and required Microsoft servicing updates.
- Windows 8.1 with .NET Framework 4.8.
- Windows 10.
- Windows 11.

## Windows 8.0
Windows 8.0 is not an official .NET Framework 4.8 target. NagiCore reports it as unsupported rather than claiming compatibility.

## Network
License verification requires HTTPS/TLS support. Local diagnostics, settings and logs do not require network access.
